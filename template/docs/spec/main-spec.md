## 目标

说明项目要解决的核心问题和用户可感知的结果。

## 背景

说明必要上下文、运行环境、现有系统事实和关键约束。只记录会影响实现判断的事实。

## 原则

- 用第一性原理确认真实约束，再决定实现。
- 非必要不增加组件、状态、文档和流程。
